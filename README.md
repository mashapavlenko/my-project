# Интерьер: сайт мебельного магазина

Адаптивный многостраничный сайт интернет-магазина мебели. Учебный проект: вёрстка по макету из Figma.

## Страницы

- Главная: hero-блок, категории, специальные предложения, каталог
- Каталог: фильтры (тип, цена, цвет), сетка товаров
- Корзина: список товаров, форма оформления заказа

## Технологии

- HTML5 (семантическая вёрстка)
- SCSS (партиалы, вложенность)
- Методология БЭМ
- Flexbox и CSS Grid
- Адаптивная вёрстка: десктоп, планшет, мобильные от 320px

## Особенности

- Мобильная версия
- Кастомные радио-кнопки, чекбоксы и слайдер цены на чистом CSS
- Hover-эффекты и анимации

## Запуск локально

```
git clone https://github.com/mashapavlenko/my-project.git
```

Открой `index.html` в браузере. Для правок стилей собери css:

```
npx sass --watch style.scss style.css
```
